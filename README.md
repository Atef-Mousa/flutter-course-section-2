# 🎲 Play Dice — Flutter Course, Section 2

A small Flutter app that rolls two dice and shows their total.
It is the practice project for **Section 2** of the Flutter course. The goal is to understand the difference between **`StatelessWidget`** and **`StatefulWidget`** and to see how **`setState()`** updates the screen.

---

## 📱 What the App Does

| Element | Description |
|---|---|
| **Total** | Shows the sum of the two dice (`total is 7`) |
| **Dice values** | Two numbers, each from **1** to **6** |
| **Roll** button | Rolls both dice with random values and updates the total |
| **Reset** button | Sets both dice back to **1** (total = **2**) |

The app uses a **dark Material 3 theme** generated from a **green** seed color.

## 🧠 Key Concept: Stateless vs Stateful

At the bottom of `lib/main.dart` there is a **commented-out `StatelessWidget` version** of the same screen. It is kept on purpose so you can compare the two versions.

### ❌ Attempt 1: `StatelessWidget`

```dart
void roll() {
  value_1 = Random().nextInt(6) + 1;
  value_2 = Random().nextInt(6) + 1;
  total = value_1 + value_2;
  print("we are in roll");   // runs, but the screen does not change!
}
```

The variables do change, and you can see the `print` message in the console, but **the screen stays the same**.
A `StatelessWidget` is never told to rebuild, so Flutter keeps showing the old values.

### ✅ Attempt 2: `StatefulWidget` + `setState()`

```dart
class playDice extends StatefulWidget {
  @override
  State<playDice> createState() => playDiceState();
}

class playDiceState extends State<playDice> {
  int value_1 = 1;
  int value_2 = 1;
  int total = 2;

  void roll() {
    setState(() {
      value_1 = Random().nextInt(6) + 1;
      value_2 = Random().nextInt(6) + 1;
      total = value_1 + value_2;
    });
  }
  ...
}
```

`setState()` tells Flutter that the data has changed and the screen needs to be updated. Flutter then calls `build()` again, and the new values appear.

> 💡 **Rule of thumb:** if the data on the screen can change while the app is running, use a `StatefulWidget` and change that data inside `setState()`.

## 🎲 How the Random Value Works

```dart
Random().nextInt(6) + 1
```

- `nextInt(6)` returns a random integer from **0 to 5**.
- Adding `+ 1` shifts the range to **1 to 6**, which matches a real die.

## 🏋️ Practice Exercises

Try these on your own after the section:

1. **Change the theme**: try another `seedColor`, or switch to `Brightness.light`.
2. **Bigger numbers**: make the dice values and the total larger with `TextStyle(fontSize: ...)`.
3. **Dice images**: replace the numbers with dice images (add them as assets in `pubspec.yaml` and use `Image.asset`).
4. **Roll counter**: add a variable that counts how many times the user pressed **roll**.
5. **Doubles message**: show a message such as *"Doubles! 🎉"* when both dice have the same value.
6. **Clean up names**: Dart convention uses `UpperCamelCase` for classes (`MyApp`, `PlayDice`) and `lowerCamelCase` for variables (`value1`, `value2`). Rename them and check that the app still works.
7. **Experiment**: remove `setState()` from `roll()` and see what happens. Can you explain why?
